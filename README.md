# TasteBridge

A two-reader book recommendation project for AC215. Each reader supplies five favorites; the proposed system returns five bridge books with a reason for each reader.

[Frontend prototype](https://tastebridge-prototype.landenini.chatgpt.site/) · [MS1 project scope](https://tastebridge-prototype.landenini.chatgpt.site/project/)

The editable frontend and build instructions are in [frontend/prototype](frontend/prototype/). The published demo currently uses sample data. Data processing, trained models, and API integration are later project components.
